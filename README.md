# Score my recipe

A tool to compute Green-Score of recipes (and other scores in the future)

Green-Score is an assesment of the environmental impact of food see https://docs.score-environnemental.com/

## Getting started

See [docs/dev-quick-start.md](docs/dev-quick-start.md) for instructions on how to run the backend from the `server/` folder.
